# Cabarrus Workshops

Independent Cabarrus Creations LLC workshop registration website.

- `index.html` — Hamilton Woodworking Show preview.
- TinkerHub (Supabase) hosts the event data and registration-status endpoint.
- **Waiver submissions are disabled** pending approved Ontario release language and a secure collection workflow.

Deploy this repository's `main` branch with Netlify using publish directory `.` and no build command.

This repository is separate from Cannon School's ThinkTank website.
